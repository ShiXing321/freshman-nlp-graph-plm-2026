# 本人练习与核查

练习时记录执行命令、改动参数、结果文件和自己的解释。可以先从已有结果选一个配置，完成一次独立复现，再沿着输入、模型、损失和输出讲清楚整个过程。

先在PowerShell里进入本目录，执行 `$env:PYTHONUTF8='1'`。不要同时启动多个训练。单项命令见各任务README；已经跑出的结果可以先读JSON和曲线。

| 任务 | 自己做一次 | 能讲清楚的内容 |
|---|---|---|
| NumPy分类 | 用3个样本手算softmax、交叉熵及一轮梯度更新；与objective函数比较 | 为什么先减最大值，为什么gradient要除batch大小，TF-IDF为什么只能fit训练集 |
| PyTorch分类 | 运行train_torch_bow，把学习率改为0.1；比较CNN随机/GloVe两份JSON | backward和step各做什么，LongTensor标签为什么必要，padding怎么屏蔽 |
| ESIM | 用两条不同长度句子打印注意力矩阵，确认每个有效行概率和为1 | 双向对齐、差值/乘积特征和mask |
| BiLSTM-CRF | 运行verify_algorithms，给2个标签3个位置手工枚举8条路径 | 配分函数与Viterbi分别求什么，实体F1与token准确率的区别 |
| 字符语言模型 | 从检查点改起始词和温度，保留自己生成的两段文本 | 输入标签错位、困惑度、为什么先分文本再造窗口 |
| 图节点分类 | 在Cora上把GCN从2层改为3层，比较验证曲线 | 邻居聚合、mask、过平滑、transductive划分 |
| 图链路预测 | 找一条测试正边，检查它不在训练消息边中 | 点积打分、负采样、AUC/AP、分区丢监督边 |
| 图级学习 | 对一张小图手算mean/max/min；比较ZINC两种训练模式 | batch向量、图分类与回归、MAE、更新次数区别 |
| 知识图谱 | 给一个三元组画出TransE向量关系，说明filtered排名 | RotatE复数旋转、ConvE卷积、MRR与Hits |
| BERT与匹配 | 看Pointwise和DSSM的输入张量；同一评论保持在一个划分 | 单塔/双塔、CLS/mean pooling、相似度阈值 |
| SimCSE | 用train.txt单句跑小批次，确认不读语义标签 | 两次Dropout视图和批内负例 |
| UIE | 找一条result_list，把字符偏移映射为token起止位置 | 条件抽取、边界损失、训练增强和原test为空的处理 |
| PET/p-tuning | 修改模板再运行PET；统计p-tuning可训练参数 | 标签词、MASK预测与连续prompt、未见类别 |
| T5 | 用infer_saved.py给问答模型输入问题和短原文 | encoder-decoder、teacher forcing、labels=-100、生成评价 |
| 零样本 | 读类别schema，选3条原始输出分析错误 | 提示必须说明类别含义，格式解析失败也算错误 |
| MBTI | 复查5道题的A/B及维度映射 | 输出倾向依赖提示，无法当作人格诊断 |
| LoRA/预训练 | 查看adapter大小；比较SFT与CPT哪些token被算损失 | 冻结基座、低秩矩阵、assistant-only mask |
| 奖励/PPO | 在本地工具中亲自给5条输出打分，并写理由 | 自动奖励与人工反馈的区别、旧策略、clip、KL、价值函数 |
| Tokenizer | 对中英文、数字、emoji分词并decode | token不等于一个汉字，字节BPE和偏移的含义 |

加载已保存模型的例子：

```powershell
.\.venv\Scripts\python.exe -X utf8 transformers_tasks/local_runs/infer_saved.py sft --text '请用一句话解释梯度下降。'
.\.venv\Scripts\python.exe -X utf8 transformers_tasks/local_runs/infer_saved.py t5_qa --text '问题：李白是哪一朝的诗人？ 原文：李白是唐代诗人。'
.\.venv\Scripts\python.exe transformers_tasks/local_runs/local_tools.py
```

本地工具地址是 http://127.0.0.1:8765 。已经运行时不用再开第二个。人工评分保存在transformers_tasks/local_runs/human_ratings.jsonl。
