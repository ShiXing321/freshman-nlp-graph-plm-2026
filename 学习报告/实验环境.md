### 模型与数据来源

| 内容 | 来源与条件 |
|---|---|
| 情感分类 | Kaggle Rotten Tomatoes，156,060短语；SentenceId分组80/10/10 |
| SNLI / CoNLL2003 | 官方划分，经HF镜像下载 |
| 唐诗 | NLP上游poetryFromTang.txt |
| Cora / CiteSeer / Flickr | PyG数据集，官方节点mask |
| MUTAG / ZINC | TUDataset；ZINC官方full划分的固定子集 |
| FB15k-237 | 官方train/valid/test |
| 中文小BERT | uer/chinese_roberta_L-2_H-128 |
| UIE | Pky/uie-base-zh，原版预训练编码器与边界头 |
| T5 | uer/t5-small-chinese-cluecorpussmall |
| 指令模型 | Qwen2.5-0.5B-Instruct |

大模型部分根据4GB显存采用Qwen 0.5B完成零样本、LoRA、继续预训练和PPO；从零训练采用4层、128维GPT2。原仓库6B/7B模型对应的流程与本机规模分别在PLM报告中列出。

运行截图由Playwright直接截取实际执行页面，同时保存命令、时间、退出码和原始输出。图片保留页面原貌。

重新建立环境：

```powershell
.\setup.ps1
```

随后将命令中的`.venv`改为`.venv-reproduce`。训练数据与模型缓存由下载脚本恢复，仓库提交包含代码、实验结果、日志、报告和截图。

[数据与模型来源清单](../运行记录/数据模型来源.json)保存文件大小、SHA-256和镜像来源，可用于核对恢复后的输入。

四个预训练模型的修订版本见[来源版本](../来源版本.json)。下载脚本按这些固定版本恢复模型。小BERT分词器由BertTokenizerFast保存，词表保留相同token顺序，换行形式随保存格式统一；来源清单记录实际使用的文件哈希。
